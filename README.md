# etext-repo

E-texts of 84000 translations of the Tibetan Buddhist canon (Kangyur and
Tengyur).

84000: Translating the Words of the Buddha publishes English translations of
canonical Tibetan works at [84000.co](https://84000.co). This repository holds
e-text editions of those translations.

## Identifying works

Works are identified by their Tohoku catalogue number (e.g. Toh 1, Toh 44),
the standard scholarly reference for texts in the Degé Kangyur and Tengyur.
